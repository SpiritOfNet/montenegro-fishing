# Рыбацкие земли · Черногория

Самостоятельный интерактивный атлас для телефона и компьютера. Готов к размещению на GitHub Pages. Сборка, сервер приложения, база данных, аккаунты и ключи API не нужны.

**39 районов и водоёмов · 19 видов и групп рыб · 19 карандашных рисунков.**

**Версия 1.2 — карандашные рыбы.** Все 12 иллюстрированных видов перерисованы в манере полевого дневника: светлые тела, графитная штриховка, неровный контур и почти монохромный рисунок. Новая таблица `assets/fish-sketches.png` используется на карте, в карточках и каталоге; исходная цветная таблица сохранена отдельно. Версия 1.3 добавляет семь недостающих рисунков: радужную форель, подуста, скадарскую уклейку, угря, сома, гольца и луфаря. Все 19 видов и групп теперь иллюстрированы. Промпт и сведения — в `assets/FISH-SKETCHES.md`.

**Версия 1.1 — рисованный атлас.** Подложка переработана по референсам внутриигровой карты RDR2: бумага, чернильные дороги, горизонтали рельефа, приглушённые воды, узкие картографические подписи и рукописные пометки. Саму игровую карту проект не использует. Данные мест, рыб и ограничений сохранены.

В режиме «Атлас» реальные дороги и воды OpenStreetMap/Geofabrik отрисовываются локально. Горизонтали с интервалом 200 м рассчитаны по Terrain Tiles; это обобщённое изображение рельефа, не точная навигационная карта. Режим «Дороги» открывает подробную сетевую подложку OpenStreetMap.

## Опубликовать на GitHub Pages

1. Распакуйте архив. Создайте репозиторий на GitHub, например `montenegro-fishing`. Для бесплатного GitHub Pages выберите публичный репозиторий.
2. Загрузите **содержимое этой папки** в корень репозитория: `index.html` должен лежать рядом с `app.js`, `data.js` и папками `assets`, `vendor`. Не загружайте ZIP вместо файлов. Пустой файл `.nojekyll` также включён; при загрузке через браузер убедитесь, что он не пропущен.
3. Откройте **Settings → Pages → Build and deployment**. В **Source** выберите **Deploy from a branch**, затем **main**, **/(root)** и **Save**.
4. После публикации адрес появится в Pages. Он будет иметь вид `https://ВАШ-ЛОГИН.github.io/montenegro-fishing/`.
5. Откройте этот адрес с телефона. Ссылку можно сохранить на главный экран через меню браузера. HTTPS на GitHub Pages также позволяет использовать геолокацию и офлайн-кэш.

Пути относительные: проект работает и по адресу репозитория с подпапкой, и на собственном домене.

Инструкция сверена 27.10.2026 с [созданием GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site) и [настройкой публикации из ветки](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Что работает

- Интерактивная карта: перемещение, масштаб, группировка близких отметок, рисунки рыб, режимы «Атлас» и «Дороги».
- Поиск на русском и по местным названиям; фильтры по морю/рекам/озёрам, части страны, рыбе, месяцу, известным запретам и описанному береговому доступу.
- Карточки водоёмов: рыба, снасти, сезонные ориентиры, ограничения, источники, характер координат и подтверждённость подхода.
- Каталог рыб с иллюстрациями и переходом к соответствующим районам.
- Избранное в текущем браузере, ссылки на место вместе с фильтрами, внешние ссылки на погоду и обзор района в Google Maps.
- На телефоне отдельные вкладки карты, списка и фильтров. Проверено на ширине 320 и 390 пикселей.
- После первого успешного посещения справочник, гравюры и рисованный атлас с дорогами, водами и горизонталями доступны без сети. Режим «Дороги», внешние источники и погода требуют интернета. Тайлы не скачиваются заранее и не сохраняются сервис-воркером.

Сайт не содержит аналитики, рекламы или учётных записей. Внешний сервер карт получает обычные запросы тайлов. Геолокация используется только после нажатия соответствующей кнопки, не сохраняется и не отправляется приложением на сервер. Избранное не синхронизируется между устройствами.

## Что означают данные

Это **исследованные рыболовные районы и водоёмы**, а не полный перечень всех разрешённых точек заброса. Для большинства мест подтверждён водоём/регион и фауна, но конкретный береговой подход не обследован. Координаты — ориентиры GeoNames. Они могут указывать на город, реку или центр озера и не заменяют точную границу правового режима.

Фильтр «Только где береговая ловля описана в источнике» выбирает районы с отдельным подтверждением береговой ловли. Это подтверждение инфраструктуры или возможности доступа, **не разрешение ловить в каждой точке**. Например, оборудованный берег у Tanki rt пересекается с упоминанием закрытых зон.

Сезонные месяцы — широкие ориентиры, а не прогноз клёва. Для угря и некоторых круглогодичных видов специфическая биологическая сезонность не установлена и фильтр их не ограничивает. При выборе месяца отдельно рассчитывается пересечение известных годовых запретов с полным месяцем: март, май, июнь и другие месяцы могут быть закрыты частично. Без выбранного месяца используется дата исследования 27.10.2026. Многолетние запреты и завершившийся сезон Дурмитора остаются исторической сводкой, а не автоматическим календарём будущих разрешений.

Указание видов не гарантирует береговой улов: часть морских источников описывает лодочную ловлю. Охраняемые щука, младица, мраморная и зетская мягкоротая форель, налим исключены из целевых видов. Группа «ручьевая / озёрная форель» не включает рекомендацию ловить эти защищённые виды.

## Актуальность и источники

Правила проверены **27 октября 2026 года**, автоматически не обновляются. Их нужно перепроверять перед поездкой. Месяц не определяет разрешённые часы, дни недели, размеры и квоты. Отсутствие красного статуса не означает подтверждённое разрешение.

- [RESEARCH-PLACES.md](RESEARCH-PLACES.md) — исследование районов, происхождение координат и береговой доступ.
- [RESEARCH-RULES.md](RESEARCH-RULES.md) — сезонные и многолетние запреты, источники и противоречия.
- Полный список ссылок доступен также в разделе «Об атласе» и карточках мест.
- [CREDITS.md](CREDITS.md) — картографические данные, библиотеки, шрифт и изображения.
- [assets/ARTWORK.md](assets/ARTWORK.md) — исходный промпт генерации гравюр и параметры отображения.

Морские парки показаны как территории с особым режимом, а не как полностью закрытые акватории. Полных правовых полигонов в приложении нет: приказ иногда описывает границы местными названиями и приложенными схемами.

## Предпросмотр на компьютере

Проще всего использовать любой локальный сервер статических файлов. Например, при установленном Python выполните из этой папки:

```sh
python -m http.server 8000
```

Откройте `http://localhost:8000`. Для публикации Python не нужен. Открытие `index.html` напрямую может работать с ограничениями браузера, но офлайн-кэш и геолокацию лучше проверять через localhost или HTTPS.

## Обновить карту

Данные находятся в `data.js`. У каждого места заданы тип, регион, координаты, виды, источники, доступ и ограничения. `sources` содержит ссылки и уровень источника; `fish` — виды, рисунки и сезонные ориентиры. Текст правового режима не следует выводить только из туристических страниц.

После изменения состава файлов или структуры кэша увеличьте `CACHE` в `sw.js`. При добавлении нового обязательного ресурса включите его в `FILES`. В `data.js` измените дату проверки только после фактической проверки правил.

Режим «Дороги» использует публичные тайлы OpenStreetMap без ключа. Не добавляйте массовое скачивание или предварительное кэширование; при большом публичном трафике выберите подходящего поставщика тайлов и соблюдайте его условия. Режим «Атлас» не требует внешней подложки.
